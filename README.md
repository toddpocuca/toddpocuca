# Todd Pocuca

I am a master's student at McMaster University in Statistics. 
I am currently interested in compilers for general numerical computing, but I previously worked on tooling for probabilistic programming and transcriptomic experiments.

My [undergraduate thesis project](https://github.com/toddpocuca/bayinx) was a Stan-like probabilistic programming language embedded in Python using JAX, inspired by Bob Carpenter's blogposts on the topic[^1][^2].

[^1]: [It’s a JAX, JAX, JAX, JAX World](https://statmodeling.stat.columbia.edu/2025/10/03/its-a-jax-jax-jax-jax-world/)
[^2]: [Stats and ML postdoc and permanent hiring season officially open at Flatiron](https://statmodeling.stat.columbia.edu/2025/09/16/stats-and-ml-postdoc-and-permanent-hiring-season-officially-open-at-flatiron/)
